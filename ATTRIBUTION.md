# Data sources and licences

Kanjilink's app code is proprietary (Vplus Studio). The kanji data bundled in
`app/src/main/assets/kanji.json` is derived from the sources below and is shared under
**CC BY-SA 4.0**, as the EDRDG licence requires.

| Source | Used for | Licence |
|---|---|---|
| [KANJIDIC2](https://www.edrdg.org/wiki/index.php/KANJIDIC_Project), Electronic Dictionary Research and Development Group (EDRDG) | Kanji, meanings, on/kun readings, stroke counts, frequency | [CC BY-SA 4.0 / EDRDG licence](https://www.edrdg.org/edrdg/licence.html) |
| JLPT N5–N1 lists by [Jonathan Waller](http://www.tanos.co.uk/jlpt/) | Level of each kanji | Credited; via kanji-data |
| [kanji-data](https://github.com/davidluzgouveia/kanji-data) by David Gouveia | The `jlpt_new` field only (no WaniKani content is used) | MIT |

## EDRDG licence duties (read 2026-11-23)
1. **Attribution in the app**: on a separate screen reached from a menu (Settings → Sources & licences),
   with links to the licence and project pages. A launch-screen mention is not enough.
2. **No copyright claim** over the dictionary data.
3. **Keep the data current**: regenerate `kanji.json` from the newest KANJIDIC2 before each release
   (`python3 tools/build_kanji_data.py kanjidic2.xml kanji.json app/src/main/assets/kanji.json`).
4. Commercial use and a closed-source app are allowed. A donation to EDRDG is suggested once the app earns.

Romaji in the data is generated by `tools/build_kanji_data.py` (Hepburn-style).
