# Kanjilink

Android app (Kotlin + Jetpack Compose) by Vplus Studio: learn kanji every time you look at your phone.
A kanji appears on the lock screen (as wallpaper), in a home-screen widget and in a gentle notification,
with spaced repetition behind it. No account, no server, progress stays on the device.

- Package: `app.vplusstudio.kanjilink` (permanent)
- Market: English first (US, UK, CA, AU), then FR/ES/PT/DE.
- Research: `ronmailx-boop/agents` → `reports/2026-11-22-global-app-ios-only-verified.md`.

## Build
```
./gradlew testDebugUnitTest assembleDebug   # tests + debug APK
./gradlew bundleRelease                     # needs KEYSTORE_PATH, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD
```
GitHub Actions (`.github/workflows/android-build.yml`) does both on every push to `main`
and uploads the debug APK, screenshots and (with the upload-key secrets) the release AAB.
